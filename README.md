# Tri-CEA Public Data Repository

A public dataset supporting Controlled Environment Agriculture (CEA) research, modeling, and decision-support across New Mexico, Wyoming, and South Dakota and their tribal communities.

## About This Repository

This repository is part of the Tri-CEA project's deliverables. It compiles publicly available data covering cost, weather, sunlight exposure, socioeconomic, and workforce variables that may affect the feasibility and performance of CEA systems. The goal is to give communities, entrepreneurs, and researchers open access to the parameters needed to evaluate and plan CEA systems in their own county or region.

## Repository Structure

- data/biophysics/ — Weather, sunlight exposure, water, and climate variables
- data/socioeconomics/ — County-level cost data: utilities, rent, fuel, taxes, labor, and budget tools
- data/workforce-development/ — Labor market and workforce training data
- data/policy-regulation/ — State and tribal policy and regulatory documentation
- docs/ — Data governance policy and metadata standards

## What's Public

This repository contains only publicly available, non-identifiable data. Raw survey data from producer, consumer, and community-organization surveys is not included, as it is collected under IRB protocols and subject to data sovereignty agreements with tribal communities. See docs/DATA_GOVERNANCE.md for details.
